01 / THE IDEA

A tactile layer.
Nothing else changes.

Haptic Cursor watches Accessibility boundaries and gives you feedback at entry. Its entire purpose is to make the existing interface easier to feel.

◎

Invisible boundaries

Detect supported macOS Accessibility elements as the pointer enters their bounds.

⌁

One clean haptic

A single feedback request per entry. No repeated pulses, snapping or inertial movement.

▦

Profiles for everything

Save named presets, disable all feedback, or customize each UI role individually.

◫

Finder + Dock aware

Best-effort support for file items, Dock icons, scrollbars, menu items and controls.

◈

Configurable patterns

Choose Apple's Alignment, Generic or Level Change feedback for each type of control.

⟡

Experimental strength

Optional private hardware waveforms for Levels 1–4. Standard mode remains available.

Download. Build. Feel.

02

Run the installer

Requires Apple Command Line Tools. The script compiles, verifies, installs, and launches the app.

03

Approve and customize

Grant macOS Accessibility access. Keep Enhanced Mode off for your first test, then configure saved profiles.

Terminal · one-command installation
(
  set -e
  ZIP="$HOME/Downloads/MenuMagnetHapticProfiles-v3.0.1.zip"
  TMP="$(mktemp -d)"
  trap 'rm -rf "$TMP"' EXIT
  unzip -q "$ZIP" -d "$TMP"
  bash "$TMP/MenuMagnetHapticProfiles-v3.0.1/install.sh"
  rm -f "$ZIP"
)

The installer removes only recognized earlier Menu Magnet application bundles after successfully compiling the replacement. It may request administrator approval for old copies in /Applications and attempts targeted resets of old app permission entries. Review the script before running it.
